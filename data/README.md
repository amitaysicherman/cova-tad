# Benchmark arrays

The paper runner uses these 15 files: `Hepatitis.npz`, `pima.npz`,
`thyroid.npz`, `breastw.npz`, `WDBC.npz`, `Parkinson.npz`, `lympho.npz`,
`wbc.mat`, `fraud.npz`, `campaign.npz`, `glass.mat`, `ionosphere.mat`,
`satimage-2.npz`, `shuttle.npz`, and `SpamBase.npz`.

Each file contains `X` (features) and `y` (the ADBench binary anomaly label).
The arrays originate from the ADBench benchmark; cite ADBench and respect the
license and terms of each underlying dataset. They are redistributed here only
to make the exact paper split auditable. If redistribution is not permitted by
the submission venue or an underlying source, remove `data/` from the public
repository and provide a checksum-verified download/preprocessing script.
