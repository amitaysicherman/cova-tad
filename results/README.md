# Result provenance

- `full_test_results.csv` is produced by `scripts/run_benchmark.py` and retains
  the natural prevalence of every canonical test split. It is the primary
  CoVA-TAD result table used by the manuscript.
- `full_test_results_seed0.csv` is the complete secondary context-seed
  sensitivity run reported as a diagnostic in the main paper.
- `ofa_tad_published.csv` contains the published OFA-TAD comparator values
  transcribed for the same 15 named datasets; these are not local reruns.
- `all_baselines_published_macro.csv` and
  `all_baselines_published_auprc.csv` contain the broader published comparison
  values used by the all-method main-paper table and figure.
- `paired_analysis.csv` is regenerated from those two canonical inputs.
- `local_iforest_results.csv` and its metadata are a same-machine executable
  control using the identical split and full test sets.
- `cova_runtime_cpu_13.csv` records a fresh CPU timing pass for the 13 datasets
  that completed during the reviewer audit; it is not an accuracy replacement
  for the canonical primary CSV.
- `iclr2027_cpu_audit/` contains separate Darwin CPU validation outputs:
  full-prevalence stabilizer sweeps, projection-count and feature-order checks,
  reference-contamination stress tests, and query-batch invariance checks.
  These files never overwrite primary results. Each row records its condition,
  split size, selected columns, metrics, and score time. Incomplete audit
  groups (notably the long full-fraud sweep) must not be reported as 15-table
  aggregates.
- `reviewer_experiments_raw.csv` and the associated summaries are created by
  `scripts/run_reviewer_experiments.py` when the full six-seed and
  projection-policy matrix is executed.
- `master_suite_results.csv` and `all_15_epsilon_*.csv` are legacy exploratory
  outputs. For test sets larger than 5,000 rows, their generating scripts kept
  every anomaly but only 2,500 normals. Their AUPRC values must not be compared
  with full-test published baselines.
- Other CSV files are exploratory case-study or ablation outputs. Their figures
  are labeled as exploratory unless regenerated by the final pipeline.

Published baseline values are transcribed from the cited OFA-TAD paper and are
not independently rerun by this repository.
